# Proposed Data Dictionary

| Field | Type | Meaning |
|---|---|---|
| customer_id | identifier | Unique customer reference |
| tenure_months | numeric | Customer relationship length |
| monthly_charges | numeric | Monthly charge |
| total_charges | numeric | Accumulated charges |
| contract_type | categorical | Contract arrangement |
| payment_method | categorical | Payment channel |
| support_contacts | numeric | Support interactions |
| usage_frequency | numeric | Usage measure |
| churn | binary | Target variable |

These are proposed planning fields, not an actual supplied dataset.
