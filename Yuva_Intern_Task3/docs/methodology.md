# Methodology

1. Define problem and target. 2. Validate schema and data quality. 3. Split data before leakage-prone transformations. 4. Build preprocessing pipelines. 5. Engineer/select features using training information. 6. Train candidates. 7. Tune with stratified cross-validation. 8. Compare metrics. 9. Evaluate the final model once on the held-out test set. 10. Interpret and choose threshold. 11. Document deployment and monitoring.
