# YuvaIntern Task 3 – Machine Learning Development and Evaluation Plan

## Project
Customer Churn Prediction and Retention Analytics.

This repository contains the complete Task 3 project plan for a Python-based supervised classification workflow. No real customer dataset was supplied, so no fabricated performance results are presented.

### Workflow
Problem Definition → Data Validation → Preprocessing → Feature Engineering → Train/Validation Split → Model Training → Hyperparameter Tuning → Cross-Validation → Test Evaluation → Interpretation → Deployment/Monitoring

### Candidate Models
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting

### Metrics
Accuracy, precision, recall, F1-score, ROC-AUC and confusion matrix, supported by stratified cross-validation.

- `reports/` completed Word report
